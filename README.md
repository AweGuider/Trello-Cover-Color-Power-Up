# Trello Cover Color Power-Up

A small Trello Power-Up prototype from September 2024. The goal: when a card moves to a chosen list, change its cover to a chosen color, so a card's stage shows on the board at a glance.

**Status: prototype.** The configuration page is built. It lists the board's lists, lets you pick a cover color, and saves the rule to the board's shared Power-Up storage. The step that applies the color when a card moves is not implemented yet.

- `index.html`: the configuration page, using the Trello Power-Up client library
- `manifest.json`: Power-Up name, capabilities and iframe connector
